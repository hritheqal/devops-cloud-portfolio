# DevOps Cloud Portfolio

A simple Node.js and Express starter project.

## Requirements

- Node.js 18 or newer
- npm

## Getting started

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Set the `PORT` environment
variable to use a different port.

For a regular start without file watching, run `npm start`.

Static files are served from `public/`.
